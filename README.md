# Stock Monitor

남는 갤럭시 스마트폰을 홈 서버로 사용하는 개인용 주가 대시보드입니다. 같은 집 Wi-Fi의 브라우저에서 한국·미국 주식과 ETF의 시세를 확인하고, 관심종목과 수동으로 생성한 투자 분석 보고서를 관리합니다.

> 아래 이미지는 2026년 9월 28일 KST에 실행 중인 서비스에서 캡처했습니다. 표시된 가격과 시장 상태는 촬영 당시 값입니다.

## 대시보드

![실제 서비스의 관심종목 대시보드 전체 화면](docs/images/dashboard.jpg)

- 한국·미국 시장의 현재 세션과 다음 마감 시각을 KST로 표시합니다.
- 전체·한국·미국·ETF 필터로 관심종목을 골라 봅니다.
- 카드에서 현재가, 원통화, 전일 대비 금액·비율, 세션 상태와 마지막 갱신 시각을 확인합니다. 상승·하락은 색상과 화살표로 함께 구분합니다.
- Toss REST로 초기 시세를 가져오고 WebSocket 체결을 SSE로 브라우저에 전달합니다. 연결이 지연되거나 끊기면 마지막 가격을 유지하고 상태를 표시합니다.

모바일에서는 카드가 한 열로 배치됩니다.

## 관심종목 관리

![실제 서비스의 관심종목 관리 전체 화면](docs/images/watchlist.jpg)

종목명이나 심볼로 한국·미국 주식과 ETF를 검색해 합계 20개까지 추가할 수 있습니다. 등록한 종목은 위·아래 버튼으로 순서를 바꾸고, 삭제 전에 확인을 받습니다. 중복 종목은 추가할 수 없습니다.

## 종목 상세와 투자 보고서

![실제 서비스의 종목 상세 및 펼친 투자 보고서 전체 화면](docs/images/instrument-report.jpg)

카드를 선택하면 해당 종목의 실시간 현재가와 최신순 투자 보고서를 봅니다. 보고서는 Mac에서 `$stock-report <종목명>` 또는 `$stock-report 관심종목 전체`를 명시적으로 실행할 때 생성·저장됩니다. 보고서를 펼치면 단기·중기 관점, 신뢰도, 사실·추론·의견·미확인 구분과 연결된 출처를 확인할 수 있습니다. 보고서가 없으면 빈 상태를 안내합니다.

## 실행과 개발

- 스마트폰에서는 Termux 네이티브 Python, FastAPI, SQLite로 실행합니다. 브라우저는 스마트폰의 홈 LAN 주소로 접속합니다.
- 설치, Toss 연결 진단, 서비스·백업·재부팅 자동 시작은 [Termux 실행 가이드](docs/TERMUX.md)를 따릅니다.
- 제품 범위와 완료 조건은 [프로젝트 계획](docs/PROJECT_PLAN.md), 브랜치·PR·배포 절차는 [개발 및 브랜치 전략](docs/DEVELOPMENT.md)에 있습니다.
- AI 개발 에이전트는 [AGENTS.md](AGENTS.md)를 작업 계약으로 사용합니다.

이 서비스는 정보 확인용입니다. 주문·계좌 기능과 외부 인터넷 공개는 지원하지 않습니다.
