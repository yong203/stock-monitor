# 프로젝트 계획

## 1. 목표

집 Wi-Fi에 연결된 기기에서 스마트폰의 IP 주소로 접속해 관심 종목의 실시간 상태를 한 화면에서 확인한다.

1차 목표는 안정적인 실시간 시세 대시보드다. 2차 목표는 Mac의 Codex가 요청받은 종목을 조사·분석해 근거가 연결된 투자 보고서를 스마트폰에 저장하고, 종목 상세 화면에서 최신순으로 보여주는 것이다.

## 2. 확정된 범위

### 사용자와 종목

- 사용자 1명, 로그인과 프로필 없음
- 한국·미국 주식 및 ETF 지원
- 관심 종목 최대 20개
- 사용자가 종목을 검색해 추가·삭제하고 순서를 변경
- 상단 금·환율·지수 영역은 만들지 않음

### 첫 화면

- 한국/미국 시장의 현재 세션, 다음 개장 또는 마감 시각 표시
- 전체/한국/미국/ETF 필터
- 사용자 지정 순서의 반응형 카드 목록
- 다크 모드 전용 UI. 별도 라이트 모드 전환은 만들지 않음
- 어두운 중성 배경과 높은 명암비를 사용하고 등락 색상은 숫자·화살표를 함께 표시
- 카드마다 종목명, 심볼·시장, ETF 여부, 현재가, 통화, 전일 대비 금액·퍼센트, 세션 상태, 마지막 갱신 시각 표시
- 상승은 빨강, 하락은 파랑, 보합은 회색으로 표시하고 화살표를 함께 사용
- 모든 시각은 KST로 표시
- 연결 지연·중단 시 마지막 값을 유지하고 `지연` 또는 `연결 끊김`을 명확히 표시
- 카드를 누르면 실시간 시세와 2차 목표의 보고서 타임라인이 있는 종목 상세 화면으로 이동
- 중복 종목은 허용하지 않고 삭제 전 확인하며 카드 순서는 사용자가 정함

### 시장 세션

- 한국은 KRX와 NXT 통합 체결 세션을 표시
- 미국은 데이·프리·정규·애프터마켓 세션을 표시
- 휴장일과 미국 서머타임을 고려하기 위해 장 시간을 직접 고정하지 않고 Toss의 거래일·세션 정보를 기준으로 판정

## 3. 기술 구조

### 스마트폰

- Termux 네이티브 Python
- FastAPI + Uvicorn 단일 프로세스
- Jinja2 HTML + 가벼운 CSS/JavaScript
- SQLite WAL 모드
- 브라우저 실시간 전달은 SSE(Server-Sent Events)
- Docker, Kubernetes, RabbitMQ, PRoot Ubuntu는 사용하지 않음

### 실시간 시세 흐름

```text
Toss REST 초기 시세/전일 종가
            ↓
Toss WebSocket 실시간 체결 → 스마트폰 메모리 캐시 → SSE → 브라우저 카드
            ↑
       재연결 시 REST 재동기화
```

- 서버 시작과 WebSocket 재연결 때 REST로 최신 값을 먼저 동기화
- 한국은 `trade:kr`, 미국은 `trade:us` 구독
- 브라우저 렌더링만 약 250ms 단위로 묶고 수신 데이터는 실시간 반영
- 전일 대비 값은 Toss 장 캘린더의 전 영업일과 일봉 `closePrice`를 기준으로 서버에서 계산
- 한국 종목은 KRW, 미국 종목은 USD로 원통화 표시
- 시장 캘린더는 전일·당일·익일의 offset 포함 세션 시각으로 판정하고 15분마다 갱신하며 세션 경계에는 즉시 화면 상태를 바꿈
- 연결 실패 시 지수 백오프로 재접속하고 성공하면 REST 값으로 다시 동기화
- OAuth 토큰은 한 곳에서만 발급·갱신해 중복 발급으로 기존 토큰이 무효화되지 않게 함
- 주문·계좌 API는 범위에서 완전히 제외

### 저장 데이터

- 관심 종목과 표시 순서
- 전일 종가 및 최소한의 종목 메타데이터
- AI 투자 분석 보고서와 출처
- 실시간 체결은 메모리에만 두고 시세 이력을 장기 저장하지 않음

## 4. AI 투자 보고서 — 2차 목표

- 사용자가 Mac의 저장소에서 `$stock-report <종목명>` 또는 `$stock-report 관심종목 전체`를 명시적으로 실행
- 스마트폰 내부 API가 관심종목과 Toss 현재가·일봉·종목 정보·유의사항·국내 수급 정보를 제공
- Codex가 Toss 데이터와 DART·SEC·거래소·발행사 IR·신뢰할 수 있는 원문 보도를 함께 조사
- 정량, 공시·펀더멘털, 반대 논리·위험 전문가 서브에이전트가 읽기 전용으로 병렬 검토
- 주 에이전트만 결과를 종합·검증하고 별도 Bearer 토큰으로 스마트폰 FastAPI에 저장
- 단기(1~4주)와 중기(3~12개월) 관점은 `우호적·중립·주의·판단 보류`와 신뢰도로 표시
- 사실·추론·의견·미확인을 구분하고 각 주장에 출처를 연결
- 카드 선택 시 별도 페이지로 이동하지 않고 같은 종목 상세 화면에서 보고서가 펼쳐짐
- 최신 보고서가 위에 오며 보고서는 1년 보관
- 동일 `run_id` 재전송은 같은 결과를 반환하고 다른 내용이면 충돌로 거절
- 기사 전문, 에이전트 대화, 비밀값은 저장하지 않음

Mac 또는 Codex가 꺼져 있어도 스마트폰의 실시간 시세는 계속 작동한다. OpenAI API, RabbitMQ, 자동 예약 실행은 현재 범위에서 사용하지 않으며 수동 흐름을 검증한 뒤 별도로 결정한다.

## 5. 홈 서버 운영

- 서버는 스마트폰 Wi-Fi 주소에서만 접근할 수 있도록 홈 LAN에서 운영
- 공유기 포트포워딩과 외부 공개는 하지 않음
- 기본 접속 주소는 `http://<스마트폰 고정 LAN IP>:8000`, LAN 한정이므로 TLS는 적용하지 않음
- 로그인이 없으므로 같은 LAN 사용자는 누구나 조회하고 관심 종목을 편집할 수 있음
- Termux 부팅 자동 시작과 서비스 자동 재시작 구성
- Android 배터리 최적화·Doze 예외, Wi-Fi 절전 방지 및 필요한 wake lock 설정
- 로그 크기 제한, DB 정기 백업, 상태 확인 엔드포인트 구성
- 스마트폰 LAN IP는 공유기 DHCP 예약으로 고정 권장
- 충전 중 발열과 배터리 팽창을 주기적으로 확인. Android가 Termux를 강제 종료할 수 있어 서버급 가용성은 보장하지 않음

### Toss 허용 IP 주의

Toss 앱 발급 과정에서 당시 집의 공인 IP가 자동 등록되었다. 이 자동 등록이 이후 IP 변경까지 추적한다고 가정하지 않는다. 공인 IP가 바뀌어 Toss 요청이 `403`으로 거절되면 화면과 로그에 허용 IP 확인 안내를 표시한다.

API 비밀값은 대화나 Git·로그에 남기지 않는다. 스마트폰의 권한 `600` 파일에 직접 입력하고 저장소에서는 제외한다. 시세 외 권한과 계좌번호는 저장하지 않는다.

## 6. 구현 단계

### Phase 0 — 기반 확인

- Toss 개발자 앱에 자동 등록된 공인 IP를 실제 연결로 확인
- OAuth 토큰에는 별도 시세 scope가 없으므로 토큰 발급과 현재가 응답 스키마 성공을 각각 확인
- 인증 성공, `403` 허용 IP 오류, 기타 API 오류를 구분하는 연결 진단 구성
- Termux 패키지 업데이트 및 Python 실행 환경 준비
- 비밀값 파일, 서비스 포트, 공유기 DHCP 예약 확정

### Phase 1 — 실시간 MVP (완료)

- 프로젝트 골격, SQLite 스키마, Toss 인증 모듈
- 종목 검색 및 관심 종목 관리
- REST 초기 동기화와 WebSocket 구독·재연결
- SSE와 반응형 카드 화면
- 시장 상태, 오류·지연 상태 처리
- 자동 시작, 로그, 백업, 상태 확인

### Phase 2 — 수동 AI 투자 보고서

- 보고서·출처 DB와 Bearer 보호 내부 API
- Toss 분석 컨텍스트와 Mac용 저장소 스킬
- 3개 전문가 서브에이전트 조사·검토 흐름
- 최신순 인라인 보고서 타임라인
- 출처 저장, 1년 보관, 멱등 저장·재시도

## 7. 1차 완료 기준

- 같은 Wi-Fi의 휴대폰·태블릿·PC에서 주소 입력만으로 화면이 열림
- 한국/미국 주식 및 ETF를 합계 20개까지 추가·삭제·정렬 가능
- 지원되는 모든 거래 세션에서 체결가가 자동 갱신됨
- 현재가와 전일 대비 금액·퍼센트가 일관되게 표시됨
- 휴장·장전·장중·장후와 다음 개장/마감이 KST로 정확히 표시됨
- 네트워크 또는 Toss 장애 뒤 자동 재연결되고 값의 신선도가 화면에 표시됨
- 스마트폰 재부팅 뒤 별도 명령 없이 서비스가 다시 시작됨

## 8. 이번 단계에서 하지 않는 것

- 다중 사용자와 로그인
- 주문, 잔고, 계좌 연동
- 외부 인터넷 공개
- 푸시 알림
- 차트와 시세 장기 보관
- 금·환율·시장 지수 상단 위젯
- 컨테이너와 오케스트레이션
- 자동 보고서 예약 실행

## 9. 운영 원칙

- 이 서비스는 정보 확인용이며 투자 조언이나 주문 시스템이 아님
- Toss와 뉴스 출처의 이용약관 범위에서 개인 가정용으로 사용
- 가장 큰 운영 위험은 공인 IP 변경에 따른 Toss `403`과 Android의 백그라운드 앱 종료
